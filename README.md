# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/coupon-app.git
```

Go to the project:

```bash
cd coupon-app
```

Install dependencies:

```bash
npm install
```

---

# ▶️ Running the App

Start Metro:

```bash
npm start
```

### Android

```bash
npm run android
```

### iOS

```bash
npm run ios
```
